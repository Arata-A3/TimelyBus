# TimelyBus (徳島バス 時刻表 & カウントダウン)

徳島バスの最新時刻表（PDF）をスマホで見やすく表示し、次のバスまでの残り時間をカウントダウンできるアプリです。

## 主な機能

- **時刻表PDFの閲覧 (メイン)**
  - アプリ内ビューアで表示。初回からスマホで文字が読める倍率で開き、ページ周囲の余白は自動でカットします。
  - 2本指で拡大・縮小、ダブルタップで「幅に合わせる ⇔ 拡大」を切り替え。画面上部の −／＋ ボタンでも操作できます。
  - **倍率と表示位置は時刻表ごとに記憶**され、次に開いたときもそのまま表示されます。
  - ホーム画面の「前回の時刻表を開く」から、最後に見た時刻表へすぐ移動できます。
  - スマホの「戻る」ボタンで前の画面に戻れます。
- **次のバスまでカウントダウン**
  - 鳴門線の主要15停留所から乗車・降車を選ぶだけで、次の便の発車までを秒単位で表示（その後の便も一覧表示）。
  - 区間の向き（下り／上り）は自動で判定。選んだ停留所は記憶されます。
  - ダイヤ（平日・土日祝）は祝日・振替休日・年末年始・阿波おどり期間も含めて自動判別。手動切替も可能です。
  - 最終便のあとは翌日の始発を表示します。
  - **出発時刻で探す**: 出発したい時刻を入れると、その時刻以降の最初の便と到着時刻を表示（前後2本ずつも表示）。
  - **到着時刻で探す**: 着きたい時刻を入れると、間に合う便のうち一番遅く出られる便を表示（前後2本ずつも表示、間に合わない便には印）。今日／明日を選べます。
  - 「このバスに乗る」で到着までのカウントダウンに切り替え（アプリを閉じても続きから表示）。
- **スマホアプリとして利用可能**
  - ブラウザの「ホーム画面に追加」機能で、通常のアプリと同じ感覚で起動できます。

## 使い方 (スマートフォン)

1. **ページを開く**: GitHub Pages等で公開されたURLにアクセスします。
2. **ホーム画面に追加する**:
   - **iPhone (Safari)**: 画面下の[共有ボタン] ➔ [ホーム画面に追加]
   - **Android (Chrome)**: 右上の[︙] ➔ [ホーム画面に追加]
3. **アプリとして起動**: ホーム画面に作成されたアイコンから、いつでも時刻表を確認できます。

## データについて
- 時刻表PDF: `pdf/` フォルダ（徳島バス株式会社 主要停留所時刻表）
- カウントダウンの時刻データ: 鳴門線 平日・土日祝のPDF（令和8年4月1日改正）から抽出して `index.html` に埋め込んでいます。ダイヤ改正時はPDFの差し替えとあわせてデータの更新が必要です。
- PDFビューアは PDF.js（cdnjs）を使用します。読み込めない場合（オフラインなど）はブラウザでPDFを直接開くボタンが表示されます。
- 本アプリは個人が利便性のために作成したものであり、公式アプリではありません。
